# Прикладной слой (Application Layer) - Expenses.Application

Этот слой содержит бизнес-логику приложения "Expenses" и обеспечивает взаимодействие между слоем представления и доменным слоем.

## Назначение

* Реализация бизнес-правил и логики приложения.
* Предоставление сервисов для выполнения операций над доменными сущностями (Author, Category, Expense, Wallet).
* Использование DTO для передачи данных между слоями.
* Взаимодействие с репозиториями для доступа к данным.
* Обработка исключений бизнес-логики.
* Определение правил маппинга между DTO и доменными сущностями с помощью AutoMapper.

## Структура проекта

* **Dependencies:** Содержит зависимости проекта.
* **DTOs:** Содержит DTO (Data Transfer Objects) для передачи данных между слоями.
    * **Author:** DTO для сущности "Автор".
    * **Category:** DTO для сущности "Категория".
    * **Expense:** DTO для сущности "Трата".
    * **Wallet:** DTO для сущности "Кошелек".
* **Exceptions:** Содержит кастомные исключения для обработки ошибок бизнес-логики.
    * **Author:** Исключения, связанные с сущностью "Автор".
    * **Category:** Исключения, связанные с сущностью "Категория".
    * **Expense:** Исключения, связанные с сущностью "Трата".
    * **Wallet:** Исключения, связанные с сущностью "Кошелек".
* **Interfaces:** Содержит интерфейсы для сервисов.
    * **Services:** Интерфейсы сервисов, определяющие контракты для выполнения операций над доменными сущностями.
* **Mappings:** Содержит профили AutoMapper для определения правил маппинга между DTO и доменными сущностями.
* **Services:** Содержит реализации сервисов, реализующие бизнес-логику приложения.

## Зависимости

Прикладной слой зависит от следующих компонентов:

* **Доменный слой (Domain Layer):** Содержит доменные сущности и бизнес-правила.
* **Слой доступа к данным (Data Access Layer):** Предоставляет доступ к данным.
* **AutoMapper:** Используется для маппинга между DTO и доменными сущностями.

## Использование

Для использования прикладного слоя необходимо:

1.  Добавить ссылку на проект `Expenses.Application` в проект слоя представления.
2.  Зарегистрировать сервисы в контейнере зависимостей.
3.  Создать экземпляр сервиса.
4.  Вызвать метод сервиса, передав необходимые DTO.
5.  Обработать возвращаемый DTO или исключение.
